# Architecture Decision Records

ADRs supersede specific choices in `../cross-vtt-sync-architecture.md` as the
project evolves — the same versioning philosophy §9.3 applies to data, applied
to the design itself (the architecture doc's closing line).

## Convention

- One file per decision, numbered (`0001-…`).
- Status: Proposed | Accepted | Superseded | Deprecated.
- Each ADR names the §N it supersedes and the date.
